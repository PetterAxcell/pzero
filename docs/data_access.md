# Data Access and Use

This repository contains code and database schema files only. It does not include Project Zero CSV data.

The dataset is expected to be distributed through controlled access on PhysioNet. Users must obtain access through the official PhysioNet workflow and comply with the applicable data use agreement, institutional policies, and local regulations.

## Important Use Notes

- Do not commit, publish, or redistribute the controlled-access CSV files through this repository.
- Do not attempt to re-identify patients, staff, admissions, institutions, or dates.
- Preserve the anonymized identifiers exactly as released when loading the data.
- Cite the dataset paper and this repository when using the database build in research outputs.
- Treat derived tables, extracts, and model-ready files as controlled data when they contain row-level patient information.

The MIT license in this repository applies to the software and documentation here, not to the clinical dataset.
